Implementation Code

The following HTML creates a table with fixed percentage column widths:

<table id="percentageTable">
    <!-- Percentage-based column widths -->
    <colgroup>
        <col style="width: 30%;"> <!-- Name -->
        <col style="width: 20%;"> <!-- Position -->
        <col style="width: 15%;"> <!-- Status -->
        <col style="width: 15%;"> <!-- Department -->
        <col style="width: 20%;"> <!-- Email -->
    </colgroup>
    <thead>
        <tr>
            <th>Name</th>
            <th>Position</th>
            <th>Status</th>
            <th>Department</th>
            <th>Email</th>
        </tr>
    </thead>
    <tbody id="tableBody">
        <!-- Table rows go here -->
    </tbody>
</table>

The essential CSS that makes this work:

table {
    width: 100%;
    border-collapse: collapse;
    table-layout: fixed; /* Critical for fixed percentages */
}

/* Column widths are controlled by colgroup */
col {
    /* Widths defined in HTML, not CSS */
}

Important Note: With table-layout: fixed, the browser calculates column widths based on:

  1. Explicit widths set on <col> elements (as percentages in this case)
  2. If no <col> widths are set, the first row of cells determines column widths
  3. When there are no rows, the <col> widths are essential for maintaining layout

Percentages in <col> elements are relative to the total table width, not the viewport.

Table column widths remain fixed at their percentage values (30%, 20%, 15%, 15%, 20%) even with no rows.

Try adding/removing rows and resizing the browser to see the percentages in action.
