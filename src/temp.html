Pig Feed Balance Input

Update feed balance values for each feed type. Use up/down buttons or directly input values.

Feed Type Buy (kg) Balance (kg)
Gesta 150
Lacta 200
Booster 180
PreStart 120
Starter 250
Grower 300
Finisher 280

Instructions

  • Feed Type column is read-only
  • Buy column shows current inventory (read from database)
  • Balance column allows input of adjusted values
  • Click up/down buttons to adjust by 0.5 kg increments
  • Directly type a value into the input field
  • Use keyboard up/down arrows when focused on the input

Note: All values are in kilograms (kg). Step increment is fixed at 0.5 kg.
