Mobile-Optimized Search

Single-line layout with compact search button on mobile

Mobile Optimized: On mobile view, the "Search" text is hidden and the button becomes a compact circle with just the search icon. Input and button stay on one line.

Mobile-Optimized Features

On mobile devices: 1) Search button shows only the magnifying glass icon (no text), 2) Input and button remain on a single line, 3) Button becomes a compact circle for better touch targets, 4) Layout adapts to various screen sizes.

How It Works

  • Desktop View - Button shows "Search" text with icon.
  • Mobile View - Button shows only the search icon in a compact circle.
  • Hit count badges - Show estimated matches in the database.
  • Single-line layout - Input and button always stay on same line.
  • Touch-friendly - Larger touch targets for mobile users.
