Pig Feed Balance Input

Update feed balance values for each feed type. Use up/down buttons or directly input values.

Feed Type Buy (Sacks) Balance (Sacks)

Instructions

1. Feed Type column is read-only and displays the fixed feed categories.

2. Buy column shows the current inventory (read-only, typically loaded from database).

3. Balance column allows input of adjusted values. You can:

  • Click the up/down buttons to adjust by 0.5 kg increments
  • Directly type a value into the input field
  • Use keyboard up/down arrows when focused on the input

Note: All values are in kilograms (kg). Step increment is fixed at 0.5 kg.
