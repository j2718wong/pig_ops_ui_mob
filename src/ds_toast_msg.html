How to Use

Toasts are lightweight notifications designed to mimic push notifications.

Basic Toast Structure:
<div class="toast" role="alert">
  <div class="toast-header">
    <strong class="me-auto">Title</strong>
    <button type="button" class="btn-close" 
            data-bs-dismiss="toast"></button>
  </div>
  <div class="toast-body">
    Your message here
  </div>
</div>
JavaScript Initialization:
// Initialize a toast
const toast = new bootstrap.Toast(toastElement, options);

// Show the toast
toast.show();

Toast Features

Positioning

Place toasts anywhere on screen

Auto-hide

Option to auto-dismiss after delay

Customizable

Style with CSS or utility classes

Interactive
